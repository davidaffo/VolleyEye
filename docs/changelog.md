# Changelog di VolleyEye

Tutte le versioni registrate nella cronologia Git, dalla più recente alla più vecchia.
Le voci storiche riportano i messaggi originali dei commit e i relativi collegamenti; i salti di numerazione riflettono le versioni effettivamente presenti nel repository. Le date indicano la registrazione in Git, non una verifica della pubblicazione online.

Prima della versione 0.1.0 il progetto era già in sviluppo, ma non aveva una numerazione di release registrata.
