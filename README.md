# VolleyEye

Applicazione open source per lo scouting della pallavolo.
Funziona interamente da browser e può funzionare offline.
Ottimizzata sia per desktop che per mobile.
Include funzionalità normalmente presenti in applicazioni professionali, quali scout live e tramite video, inserimento tramite codice standard, analisi approfondita, sincronizzazione video e permette di importare ed esportare anche in formato DataVolley.

Utilizzabile da [https://davidaffo.github.io/VolleyEye/](url)
